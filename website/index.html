Features

Everything you need to run a session

From seating to scoring to export, the Bridge Box handles the full session so directors can focus on the room, not the maths.

⚡

Live score entry

Players enter their own results at the table, confirmed by both sides. Every device updates in real time as boards come in.

♠

Pairs & Teams movements

Mitchell, Howell, American Whist, plus Swiss Pairs and Swiss Teams. Run several sections at once, each with its own movement.

⏱

Session timer

A per-section timer with play, move and break phases, plus live director controls to pause, adjust or skip on the fly.

🏆

Live leaderboard

Standings update as results arrive, shown per-section and combined — ready for the room display screen.

📋

Traveller sheets

View results by board as they come in, and correct any that were entered wrong — including adjusted scores such as a 60/40 split.

📊

MP, IMP & Cross-IMP

Matchpoint, IMP and Cross-IMP scoring built in, so the method suits the event you are running.

How it works

Plug in and play — no internet required

The Bridge Box is self-contained. It brings its own network to the venue, so a whole session runs even where there is no WiFi or mobile signal.

  1. Plug in the Bridge Box

    Switch on the appliance at the venue. There is nothing to install and no accounts to set up on the day.

  2. It creates its own network

    The Bridge Box starts a local network for the room. All scoring traffic stays on it — no venue internet needed.

  3. Everyone connects

    Players and directors join from their own phones and tablets in a browser. The director who creates the game manages it.

  4. Score in real time

    Results are entered at the table and confirmed by both sides. Leaderboards and travellers update live on every device.

Optional cloud services

Connect to the cloud when it suits you

Every session runs fully offline on the local network. When you want more, the Bridge Box can optionally connect to the internet for subscription cloud services:

  • Publish event results to the BridgeBox website for members to view
  • Upload results to your club's BridgeWebs website
  • Receive software updates for the appliance
  • Back up the appliance's data

These are additive. Running a session never requires an internet connection or a subscription — the offline core does it all.

Compatibility

Fits the tools you already use

🌐

BridgeWebs integration

Connect your club's BridgeWebs account to pull up the day's events when you create a game, then upload results and hand records straight to your BridgeWebs website in one tap.

📤

USEBIO export

Export results as a standard USEBIO XML file at the end of the session — ready to upload to the EBU or import into your scoring program.

🔎

EBU player database

Search the EBU player database when players sign in, so names and numbers are captured accurately from the start.
