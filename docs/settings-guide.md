# Settings Guide

The **Settings** area covers the **Bridge Box** itself rather than any single
game. Open it from the **⚙ cog** in the top-right of the home screen.

Settings has these options:

- **WiFi Settings**
- **BridgeWebs**
- **EBU**
- **Cloud Backup**
- **Update Admin Key**
- **Log Out**

Settings is protected by the Bridge Box's **admin key** — a secret the Bridge
Box's owner sets. The first time you open Settings on a device you are asked
to enter it; you won't be asked again on that device until you **Log Out**. If
you are asked again partway through ("Session expired. Please re-enter the
admin key."), enter the key and carry on.

> The admin key protects the Bridge Box's settings; it is not a per-game
> director code. Directors do not need it to run a game.

---

## WiFi Settings

Use this to connect the Bridge Box **out to the internet**. An internet
connection lets the Bridge Box:

- **Publish results** to the club's BridgeWebs website.
- **Receive updates** to keep the Bridge Box up to date.
- **Back up** the data held on the Bridge Box.

These cloud services require a subscription.

This internet connection is separate from the local network the Bridge Box
creates for players to join — that always stays on, so players can keep entering
results during a session even if there is no internet at the venue.

1. Open **Settings → WiFi Settings**. The Bridge Box looks for nearby networks
   automatically and fills the list. If you don't see the one you want, tap
   **Rescan**.
2. Pick a network from the **Network** dropdown (signal strength is shown next
   to each).
3. Enter the network **password**.
4. Tap **Test Connection**. The app checks the credentials work.
5. Once a network has tested successfully, **Save & Apply** becomes available —
   tap it to connect the Bridge Box to that network.

If the test fails, re-check the password and try again. **Save & Apply** stays
disabled until a successful test, so you can't accidentally save bad
credentials.

## BridgeWebs

Connects the Bridge Box to your club's **BridgeWebs** website, so that:

- when creating a game you can pick from the day's events listed on BridgeWebs
  (which fills in the event name), and
- at the end of a session a director can **Upload to BridgeWebs** from **Export
  & Publish**.

1. Open **Settings → BridgeWebs**.
2. Enter the **BridgeWebs Club Code** (your club's BridgeWebs name, e.g.
   *anytownbc*) and the **BridgeWebs Password**.
3. Tap **Save**. You'll see **BridgeWebs settings saved**.

The first time, both the club code and the password are needed. Once a password
is saved the screen says **A password is saved. Leave blank to keep it.** — so
to change only the club code, leave the password empty. The saved password is
never shown again; to change it, type the new one.

Publishing needs the Bridge Box to be connected to the internet (see
[WiFi Settings](#wifi-settings)).

## EBU

Records your club's details and, optionally, connects the Bridge Box to your
club's **EBU** account.

- The **Club Name** and **EBU Club Number** identify the club on published
  results and on the files you export. Both are needed.
- The **EBU Password** is only needed if a director will **Submit to EBU** from
  **Export & Publish** at the end of a session, for masterpoints and NGS
  grading. You can leave it empty and add it later.

1. Open **Settings → EBU**.
2. Enter the **Club Name** and the **EBU Club Number**.
3. If you will submit results to the EBU, enter the **EBU Password**.
4. Tap **Save**. You'll see **EBU settings saved**.

Until the club name and number are set, no results file can be made — the
**Export & Publish** screen shows **Club information** as **Not ready** (see
the [Director Guide](director-guide.md#exporting-and-publishing-results)).

Once a password is saved the screen says **A password is saved. Leave blank to
keep it.** — so to change only the club details, leave the password empty. The
saved password is never shown again; to change it, type the new one.
Submitting needs the Bridge Box to be connected to the internet (see
[WiFi Settings](#wifi-settings)).

## Cloud Backup

Shows whether the games on this Bridge Box are being backed up off the box.
Cloud backup is part of the subscription.

- If it isn't part of your subscription, the screen says **Cloud backup is not
  enabled on this box**. Your games are still kept safely on the Bridge Box
  itself.
- If it is, the Bridge Box backs up your games automatically. **Games backed
  up** shows when that last happened (for example "3 minutes ago"), or **Not
  yet**.
- **Back up now** starts a backup straight away — useful right after a session,
  before switching the Bridge Box off. You'll see **Backup started**.

If the last backup didn't finish, the screen says so in a short note (for
example because the Bridge Box was offline). It tries again by itself, so there
is nothing you need to do — just check it is connected to the internet.

---

## Update Admin Key

Sets or changes the Bridge Box's **admin key** — the secret that protects its
settings. Keep it somewhere safe; you will need it to change protected settings
in future.

---

## Log Out

Tap **Log Out** at the bottom of the Settings screen to lock the settings again
on this device. You are taken back to the home screen. The next time anyone opens a protected setting on this device,
they will need to enter the admin key.

Use this on a shared phone or tablet when you have finished changing settings,
so the Bridge Box's settings aren't left unlocked for the next person.
