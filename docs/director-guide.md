# Director Guide

This guide explains how to run a session as a director: creating a game,
arranging tables and sections, choosing movements, running the timer,
correcting results and making rulings, and exporting and publishing the
results.

You direct from your own phone or tablet, connected to the Bridge Box's
network — the same way players connect. Whoever creates a game becomes its
director on that device; to let a co-director help from another device, you
share a code (see [Sharing director access](#sharing-director-access)).

---

## Creating a game

### Step 1: Open the create form

From the home screen, tap **Create Game**.

The create form is split across two pages so neither screen is crowded.

### Step 2: Name the event and director

| Field             | Description                                   |
| ----------------- | --------------------------------------------- |
| **Event Name**    | The name of your event (e.g. "Monday Pairs"). |
| **Director Name** | Your name.                                     |

Both are required. If you tap **Next** with either box empty, the empty box is
highlighted so you can see what's missing; fill both in and tap **Next** again
to continue.

The session is always dated today, so there is no date to set.

If your club has set up BridgeWebs (see the settings guide) and there are
BridgeWebs events listed for today, a **Use BridgeWebs Event** switch appears
above **Event Name**. Turn it **on** to pick the event from a list of the day's
BridgeWebs events instead of typing the name; picking one fills in the event
name for you. Turn it **off** to type the name yourself. The switch is hidden
when BridgeWebs isn't set up or there are no events for today, so you just type
the name as normal.

Tap **Next**.

### Step 3: Choose the event options

| Field                   | Description                                                       |
| ----------------------- | ----------------------------------------------------------------- |
| **Event Type**          | **Pairs**, **Teams**, **Swiss Pairs**, or **Swiss Teams**. The Swiss options are drawn round by round as the event runs (see the Movements tab); the Pairs and Teams options use a fixed movement you pick from a list. |
| **Scoring**             | How the event is scored. For **Pairs** and **Swiss Pairs**: **Matchpoints** or **Cross-IMPs**. For **Teams**: **IMP (Aggregate)** (teams ranked on their total IMPs across all boards), **IMP (Victory Points)** (each match's IMP result converted to Victory Points, then totalled), or the board-comparison method for your region — shown as **Point-a-Board** on UK boxes and **Board-a-Match** on US boxes (the same method under each region's usual name). **Swiss Teams** is always scored by **IMP (Victory Points)** — the only method that fits the round-by-round draw — so no scoring choice is shown for it. Defaults to Matchpoints for Pairs and IMP for Teams. |
| **Record Opening Lead** | **Yes/No** — whether players are asked to enter the opening lead. |
| **Allow Hand Entry**    | **Yes/No** — whether players can enter the hands (the four players' cards) at the end of a round. |

Need to change the name or director? Tap the back arrow to return to the first
page — what you entered is kept.

Tap **Create Game**.

> **No PIN to set.** Whoever creates the game automatically becomes its
> director on the phone or tablet they used — there is no director PIN to
> choose. Director access stays on that phone or tablet; to let someone else
> direct, you share a code (see below). The number of tables, sections, and the
> movement are all chosen on the next screen, not on these pages.

You are taken to the **setup** screen for the new game.

## Setting up the game

Setup has three tabs. You can move between them freely, and you don't have to
finish them in order.

```
Tables  →  Movements  →  Timer
```

The back arrow (top-left) on any of these tabs takes you back to whichever
setup tab you were on just before — so if you came to Movements from Tables,
back returns you to Tables. A second back from there doesn't bounce you between
the two tabs; it opens the **Edit Event Details** screen instead. And if you
haven't moved between the tabs yet (you've only just arrived at setup), the
back arrow opens **Edit Event Details** straight away — pre-filled with what
you set when creating the game — the
event name, director, event type, scoring, tournament level, and the Record
Opening Lead / Allow Hand Entry switches. Adjust anything there and tap **Save**
to return to setup, or use its back arrow to return without changes.

> **Note:** changing the **event type** or **scoring** here clears the movement
> you've already selected (the two have to match), so you'll be asked to confirm
> and will need to pick a movement again on the Movements tab.

### Tables tab

This shows each table with its four seats, filling in live as players sit down.
On a larger screen each taken seat shows the player's name; on a small screen it
simply shows the seat as **Taken** to keep the tables readable — tap the table
to open its dialog and see who is sitting there.

From this tab you can:

- **Resize a section** — use the **Tables** stepper to change how many tables
  a section has.
- **Add or remove a table** — a table can only be removed if it is the last
  one and is empty.
- **Manage a table** — tap a table to open its dialog, which lists the two
  pairs seated there (North/South and East/West).
- **Evict a pair** — in a table's dialog, tap **Evict pair** next to a pair and
  confirm "Evict this pair from the table?" (useful if someone sat in the wrong
  place). Eviction is only for sorting out seating **before the game starts**.
  Once play is under way a pair cannot be evicted this way, because their
  results are already part of the scoring — removing a pair mid-session is a
  withdrawal (see **Withdraw, mark late, or without standing** below).
- **Mark a pair "without standing"** — before the game starts, a table's dialog
  lets you flip a seated pair to **Without standing**. Use this for a
  substitute pair who is sitting in for the whole session: their results still
  count for the pairs they play against, but they do not appear in the final
  ranking themselves.
- **Expect a pair to arrive late** — if a pair hasn't turned up yet, you don't
  have to wait. Open their empty seat's table dialog and turn on **Expected
  late**. You can mark as many empty seats as you need, then start the session;
  those tables play on as soon as the pair arrives, and the pairs who face an
  empty seat meanwhile are looked after in the scoring (see **Late arrivals**).
  When the pair arrives they simply join and sit down in the usual way.
- **Withdraw, mark late, or without standing (after the game starts)** — once
  play is under way, a table's dialog replaces "Evict" with a **Change
  standing** button for each pair. From there you can mark a pair:
  - **Withdrawn** — they have stopped playing. Choose the round it happened in,
    and whether to **Remove** them from the ranking (e.g. illness) or keep them
    in with a **Penalty** (and a fine percentage). Their unplayed boards and
    their opponents' are handled per the scoring rules.
  - **Late** — they arrived part-way through. If they played at least half the
    boards they keep their place in the ranking; if not, their missed boards
    are scored like a withdrawal (choose Remove or Penalty as above).
  - **Without standing** — as above, their results count for opponents but not
    for themselves.
  - **Active** — put a pair back to normal if you marked them by mistake.
  A small badge on the pair shows its current standing at a glance.
- **A pair's phone has died** — you don't need to withdraw them. Open **Pairs**
  from the Manage Game Menu, tap the pair, and choose **Move to a new device**.
  Give the code that appears to the pair; on their new device they open the
  game, choose **Move a seat to this device**, and enter it. They carry on from
  where they were, still **Active**, with nothing marked as missed. The old
  device is signed out of the seat. (If the pair still has the old phone, they
  can do the same themselves from **Menu → Change device**.)

Once you've chosen a movement for the section, each table also shows the
**boards to put out there** at the start — for example "Boards 1–3". This is a
setup aid so you can walk the room and lay the boards out on the right tables.
Where a movement needs more than one physical set of the same boards, the copy
is named too ("Boards 1–3 (Copy A)"). If two tables start on the same boards it
notes "Shares with table 2", and where boards are passed between two tables it
notes a "Relay". If you resize the section so it no longer matches the movement
you picked, this board guidance (and the stationary-pair markers) disappear
until the counts line up again.

The app also checks the setup and flags anything that would stop the game
starting. If a table isn't full, it shows which seat will **sit out** each
round so the movement still works. A session allows **one** such sit-out; if
more than one seat is empty, start is blocked **unless** you mark the extra
empty seats **Expected late** (above), which lets you get under way with any
number of seats still to be filled.

For a **Swiss Pairs** section, a table's dialog also lets you mark **stationary
pairs**: turn on **Stationary** for a pair to keep them at their table and
direction for the whole event (their opponents come to them), and turn it off to
let them move. Stationary pairs are shown with an amber "Stationary" marker on
the table. You can change this at any time, **including once the game is
running**: a change applies to the rounds you draw from then on, and rounds
already drawn stay exactly as they were played. (A pair that has since moved
away is brought back to its home seat when you draw the next round.)

When you're ready, tap **Start Game**.

### Movements tab

Here you choose the movement — the schedule of who plays whom, at which table,
on which boards. What this tab shows depends on the **Event Type** you picked
when creating the game:

- **Pairs** and **Teams** show the movement picker — a list of ready-made
  movements to choose from (described below).
- **Swiss Pairs** and **Swiss Teams** show only the Swiss setup instead, since
  a Swiss event has no fixed schedule to pick — it is drawn round by round as
  the event runs (see [Swiss Pairs](#swiss-pairs) and
  [Swiss Teams](#swiss-teams) below).

For a **Pairs** or **Teams** game you can also split the event into sections:

- **Single section (the common case):** you go straight to the movement
  picker. An amber **"Add Section"** banner lets you split the game into
  multiple sections if you need to.
- **Multiple sections:** you get a section manager where you can add, rename,
  and delete sections, and choose a movement **for each section**
  independently.

A Swiss event always runs as a single section, so it has no "Add Section"
option.

When you have more than one section, the section manager also has a **Combined /
Separate** switch for the rankings:

- **Combined** (the default) — as well as each section's own ranking, the app
  produces one overall ranking that pools every section together.
- **Separate** — each section is ranked on its own, with no combined overall
  ranking.

You can change this at any time; the leaderboard and any room display update to
match straight away.

The movement picker shows the recommended movements for your table count,
**grouped by how many boards a pair plays** (which effectively determines
session length). Each option is a card showing the movement name, number of
rounds, boards per round, boards per set, and a short note of pros and cons.

Tap the card whose session length and board count suit your event to open its
details — the full round-by-round and table-by-table breakdown of who plays
whom on which boards. If it's the one you want, tap **Select Movement** to lock
it in for the section; otherwise tap back to return to the list and compare
another.

#### Swiss Pairs

When you pick **Swiss Pairs** as the event type, the Movements tab shows the
Swiss setup directly — the number of rounds, boards per round, and how to handle
an odd number of pairs. Set these and tap **Select Movement** to confirm. You
draw each later round during play from the game menu (see
[Drawing the next Swiss round](#drawing-the-next-swiss-round)).

The setup also asks how to handle an **odd number of pairs** each round:

- **Bye** (the default) — one pair sits out each round and is credited an
  above-average result. Simple, and fine for most club events.
- **2 half matches** — instead of a pair sitting out, three pairs play a group
  at one table: one pair (the **anchor**) plays the full round, split into two
  halves against two different opponents, and the other two each play one half
  (and are credited an average-plus for the half they miss). No one sits out a
  whole round. Choosing this reveals a per-round plan so you can pick **Bye** or
  **Half matches** for each round individually — the usual EBU practice is to
  vary it across the event. These settings only take effect if your field turns
  out to be odd; an even field ignores them.

Swiss Pairs always runs as a single section.

#### Swiss Teams

When you pick **Swiss Teams** as the event type, the Movements tab shows the
Swiss Teams setup directly. A team is simply the two pairs you seat at one
table — the North/South pair and the East/West pair — so there is no separate
team sign-up. Set the **rounds** and **boards per round** (the number of teams
comes from your table count), and tap **Select Movement**.

Each round, two teams play the same boards against each other in two rooms:
every team's North/South pair stays at their home table, and their other pair
moves to the opponents' table. The first round is a random draw; you draw each
later round from the standings during play (see
[Drawing the next Swiss round](#drawing-the-next-swiss-round)).

Swiss Teams runs in a single section. With an **even number of teams** every
round pairs cleanly. With an **odd number of teams** the dialog asks how to
handle the odd team each round:

- **Bye** (the default) — one team sits out each round (the lowest-ranked team
  that hasn't had a bye) and is credited an above-average result. Simple, and
  fine for most club events.
- **Triple** — instead of a team sitting out, three teams play a **three-way**:
  each of the three plays both of the others, so no one sits out. Choosing this
  reveals a per-round plan where you set each round to:
  - **Short** — the whole three-way runs in that one round (each pairing plays
    half the round's boards), or
  - **Long** — the three-way is spread over **two** rounds on full boards. A
    long triple therefore takes two neighbouring rounds, so mark **Long** on two
    rounds in a row.

  The three teams are the lowest-ranked three that haven't had a triple
  recently. These settings only take effect if your field is odd; an even field
  ignores them.

### Timer tab (optional)

Here you set up the round timer **before** the game starts: phase lengths,
breaks, and the warning time. Your changes are kept as you make them. Setting up
a timer is never required to start a game.

Before the game starts you can only configure the timer here — you cannot run
it. If you have set up a timer, it begins automatically when you tap **Start
Game**, and from then on you control it (start, pause, adjust) from **Timer** on
the Manage Game Menu. See [The timer](#the-timer).

Each **section** has its own timer, so sections running at different speeds can
be timed independently. When your game has more than one section, a section
selector appears at the top of the Timer tab — pick a section, then set its
timer. If every section runs to the same timing, set one up and tap **Apply to
all sections** to copy it to them all.

## Managing a running game

### Opening the director menu

1. From the home screen, tap **Manage Game**.
2. Tap your game in the list.
3. If you created the game on this device, you go straight to the **Manage
   Game Menu**.
4. If you are managing from a **different** device for the first time, you are
   asked for a **share code** — enter it to claim director access (see
   [Sharing director access](#sharing-director-access)).

### Switching between playing and managing

If you are also playing in the game, your device can act as both a player and
the director, and you can flip between the two with one tap:

- On your **play** screens there is a **Manage** control (in the header, or in
  the ⋯ menu on a small screen) that takes you to the Manage Game Menu.
- On the **manage** screens there is a **Play** control that jumps straight back
  to your table. If you are not sitting at a table on this device, it reads
  **Join** instead and takes you to seat selection so you can take a seat.

The Manage control only appears on devices that have director access. Switching
does not sign you out of either role, so you can move back and forth freely — for
example, to correct a board and then return to enter your own table's result.

### The Manage Game Menu

| Option                    | What it does                                                              |
| ------------------------- | ------------------------------------------------------------------------- |
| **Set Up Game**           | Returns to the Tables / Movements / Timer setup tabs. Shown only before the game starts. |
| **Manage Tables**         | Opens the Tables view while the game is in progress — to withdraw, mark late, or re-seat pairs. |
| **Travellers**            | View results by board, correct any that were entered wrong, and make director rulings (see [Correcting results](#correcting-results)). |
| **Enter Deals**           | Enter or correct the dealt cards (the four hands) for any board, or import them all from a dealing machine's PBN file (see [Importing the deals from a PBN file](#importing-the-deals-from-a-pbn-file)). |
| **Movement**              | View or change the movement; in a Swiss event, draw the next round.       |
| **Timer**                 | The live timer controls: start, pause, step between phases, add or take off time (see [Controlling a running timer](#controlling-a-running-timer)). |
| **Review Mismatches**     | _Swiss events only._ Check for pairs or teams that were drawn against the wrong opponents after a result was corrected (see [Reviewing Swiss mismatches](#reviewing-swiss-mismatches)). |
| **Pairs**                 | Every pair's status, plus per-pair actions such as **Move to a new device**. |
| **Export & Publish**      | Download or publish the results (see [Exporting and publishing results](#exporting-and-publishing-results)). |
| **Delete Game** _(red)_   | Permanently delete the game. This cannot be undone.                       |

**Delete Game** is always there. The other options (apart from **Set Up Game**)
appear once the game has started.

Before the game starts, the **timer** is set up on **Set Up Game → Timer
tab**. Once the game is in progress, tap **Timer** on the Manage Game Menu for
the live timer controls (start, pause, adjust).

### Drawing the next Swiss round

In a **Swiss Pairs** game, the **Movement** screen shows a **Draw Next Round**
button. It stays disabled until **every result for the current round is in**, so
you have time to enter any adjusted scores first.

When you tap it, the app works out the next round from the current standings —
pairing close-ranked pairs and avoiding repeat opponents, honouring any
stationary pairs — and shows you a **review** of the proposed seating **before
anything is saved**: each table with the two pairs' names, and the pair sitting
out (the bye) if the field is odd. **Nothing is committed until you accept it.**

On the review screen you can:

- **Swap two pairs** — tap one pair, then another, and they exchange seats.
- **Reassign the bye** — tap a seated pair, then the **sit-out** slot, to give
  that pair the bye instead.
- **OK** — commit the seating exactly as shown; the new round's seating then
  appears on every device.
- **Cancel** — discard the draw and go back; nothing is saved, so you can draw
  again.

As you adjust, the app re-checks the seating and warns you (without blocking) if
a pairing repeats an earlier-round opponent, a stationary pair is off its home
seat, or the pair you've given the bye has already had one. You're free to
accept an override anyway — the warnings are advice, not a barrier.

- An odd number of pairs is handled the way you chose when you set the movement
  up. With **Bye**, one pair sits out that round (the app suggests one from near
  the bottom who hasn't yet had one) and is credited an above-average score.
  With **2 half matches** for that round, three pairs instead play a group at
  one table — the review shows that group with the anchor and its two
  opponents — so no one sits out the whole round; each of the three is credited
  for the boards they play plus, for the two non-anchors, an average-plus for
  the half they miss. Draw and score it exactly like any other round.

Repeat this each round until the event is complete.

#### Swiss Teams

A **Swiss Teams** game has the same **Draw Next Round** button on the
**Movement** screen, enabled once all the round's results are in. Drawing shows
a **review** of the proposed round before anything is saved: each **match**
between two teams (by name, with each team's current total), plus the team
sitting out (the bye) or the three-way **triple** when the field is odd. A
triple is shown as its three head-to-head pairings; a **long** triple notes
that it runs over this round and the next. (A long triple's second round isn't
drawn afresh — the same three teams carry over automatically — so you simply
draw it like any other round when its first round is scored.)

On the review screen you can **swap two teams** — tap one team, then another,
and they exchange places for the round. Because a swap moves a team wherever it
sits, one tap-pair can re-pair two matches, change which team sits out (swap a
match team with the bye team) or reshape the three-way (swap a team in or out of
the triple). If a resulting match repeats an earlier-round opponent, that match
card is highlighted and a note tells you so — you can swap again to avoid it or
accept it as shown; the warning never blocks you.

Tap **OK** to commit the round exactly as shown — edited or not — and it then
appears on every device, with each team's away pair told which table to move to;
or **Cancel** to discard it and draw again.

### Reviewing Swiss mismatches

Each Swiss round is drawn from the standings at the time. If you later correct a
result from an earlier round, the standings change — and a round already drawn
may have paired some pairs (or teams) against the wrong opponents. The EBU calls
this a **mismatch**: a pair met opponents whose score is **more than 5 VP** away
from the opponents the corrected standings would have given them.

To check, open **Review Mismatches** from the Manage Game Menu (Swiss events
only). If nothing is affected it says **No mismatches to review**. Otherwise
there is a card for each pair or team that may have been mismatched, showing the
round and table, the opponents they actually met and the ones they should have
met (with each one's current Victory Points), and whether the actual opponents
were **stronger** or **weaker**.

For each card, decide whether it was a genuine mismatch:

- **Apply — not their fault** or **Apply — their own fault** — rule it a
  mismatch. Only that pair's Victory Points for that round change; their
  opponents' score and the boards played stay as they were:
  - Against **stronger** opponents, **not their fault**: they are compensated —
    5 VP plus three-quarters of what they scored (10 VP becomes 12.5).
  - Against **weaker** opponents, **their own fault**: they lose a quarter of
    what they scored above 5 VP (10 VP becomes 9, rounded in their favour).
  - The other two combinations leave their score unchanged, but the ruling is
    still recorded.
- **Not a mismatch** — dismiss the card, for example when the pair could
  equally well have been drawn against several different opponents. No score
  changes. The card is only cleared from the list you are looking at; it is
  shown again the next time you open **Review Mismatches**.

Each card is ruled on its own. Ruling one pair leaves the round's other cards in
the list, including the card for that pair's own opponents if they were
mismatched too. A pair you have ruled is not listed again.

You can also rule a mismatch directly from **Travellers**: tap a row of the
match and choose **Mismatch (Swiss)**.

## The timer

The timer shows players how long is left in each phase and, on the
[Room Display](room-display-guide.md), a large countdown for the whole room.
Each section has its own timer.

### Setting it up

Before the game starts, set the timer up on the **Timer** tab. In a
multi-section game, first choose the section from the selector at the top; the
settings below apply to the chosen section. The configuration has:

- **Boards / Round** and **Total Rounds**.
- **Timing Mode** — **Per Round** (one play period per round) or **Per Board**
  (play time per board × boards = the round's play time).
- **Play Duration** — minutes and seconds for playing.
- **Move Duration** — minutes and seconds for the changeover between rounds.
- **Warning at** — how many seconds before the end of play the display should
  turn red as a warning.
- **Breaks** — see below.

When you pick a movement, the timer starts from a sensible default: **7 minutes
30 seconds of play per board** with a **1 minute 30 second** changeover. Adjust
any of these to suit your event.

> **Swiss events time differently.** In a **Swiss Pairs** or **Swiss Teams**
> event there is no fixed changeover between rounds — the next round only begins
> once you draw it from the standings. So the Timer tab for a Swiss event shows
> no **Move Duration** and no **Breaks**: you set only the play duration (and
> warning). When a round's play time runs out the timer simply shows that it is
> waiting for the next round; drawing the next round (see
> [Drawing the next Swiss round](#drawing-the-next-swiss-round)) starts that
> round's play clock automatically.

The panel previews the **session length** and an estimated **finish time**.

Your settings are kept as you change them, for the section you have chosen —
in a multi-section game, choose each section in turn and set it up. The timer
does not start yet: it begins running automatically when you tap **Start
Game**. You can come back and change the settings any time before you start.

### Breaks

Tap **+ Add break** to schedule a break **after a given round**. Each break is
either:

- **Duration** — a fixed number of minutes, or
- **Resume at time** — a wall-clock time (HH:MM) to resume; the app shows the
  approximate break length.

If a break is set to resume before play could realistically finish, the app
flags it as an invalid break so you can fix it.

### Controlling a running timer

Once the game has started, tap **Timer** on the Manage Game Menu to open **Timer
Controls**. In a multi-section game, pick the section from the selector at the
top; the controls act on that section's timer. The timer's settings (phase
lengths, breaks) are fixed once play begins; what you can do is run it:

- **Start / Pause** — one button that toggles depending on the current state.
- **‹ Prev** and **Next ›** — move to the previous or next phase.
- **Adjust current phase** — **−1m / −15s / +15s / +1m** buttons, with a
  checkbox **"Apply to all subsequent phases of this type"** to apply the
  same adjustment to every future phase of that kind.

The status panel shows the **Status** (the current phase, or paused),
**Remaining** time, the **Round**, and **Live End** — the time the session is
now expected to finish.

## Correcting results

If a board was entered incorrectly, you can override it:

1. From the Manage Game Menu, tap **Travellers**.
2. Choose the **board number** to correct.
3. You see every instance of that board (each table/round it was played at),
   live. Tap the line you want to fix. If the board's cards have been entered, a
   **Show hand** button here lets you view the four hands.

   For a **Teams** game the board is grouped into **team matches**: each card
   shows the two teams by name, with a row for each room — the open room at one
   team's table and the closed room at the other's — and the board's IMP margin.
   Tap the room you want to correct. (A three-way triple's board belongs to one
   of its pairings, so it shows as an ordinary two-team card too; a Pairs game
   shows the usual flat NS/EW list.)
4. Enter the correct result step by step, the same way players enter one
   (contract, or **Pass Out** / **Not Played**). You also get two extra
   director-only options:
   - **Adjusted Score** — a direct percentage award to each side (for example
     60/40 or 50/50). Use this when you want to assign a flat average, average
     plus, or average minus without reference to any particular contract.
   - **Weighted Score** — a probability-weighted combination of real contract
     results (for example 80% of 3NT making, 20% of 3NT+1). Use this when the
     ruling calls for a weighted split between possible outcomes. You add one or
     more contract results, each with a percentage weight that together must
     total 100%, and the app scores each component against the rest of the
     field, then takes the weighted average.

   Both types of assigned score count towards the live leaderboard and the
   exported results.

   Depending on the event, the same screen offers rulings that go beyond one
   board's score:

   | Option | Offered in | What it does |
   | --- | --- | --- |
   | **Cancel / Foul Board** | Every event | The board can't stand (fouled, mis-dealt and so on). Choose the averages to award, as for an adjusted score (for example AVE+ / AVE−). |
   | **Mark Played Reversed** / **Clear Reversed** | Every event | The board was played the wrong way round, usually because the arrows weren't switched. See [A board played the wrong way round](#a-board-played-the-wrong-way-round). |
   | **Board Not Played (Teams)** | Teams and Swiss Teams | The board couldn't be played in this match. Choose who was at fault: the side not at fault gains 3 IMPs on it and the side at fault loses 3 (neither or both at fault: no swing). In Point-a-Board or Board-a-Match, the board is won, lost or tied instead. |
   | **Void Match (Teams)** | Teams and Swiss Teams | The whole match can't stand. **Incorrect seating / cannot replay** gives each team 40% of the Victory Points (8 of 20), or 60% (12) when the director was at fault. **Less than half played** gives averages by who was at fault. |
   | **Void Match (Pairs)** | Swiss Pairs | The whole match can't stand. It no longer counts against the rest of the field, and each pair gets averages by who was at fault: the side not at fault AVE+ and the side at fault AVE−, or AVE+ to both if neither was at fault and AVE− to both if both were. |
   | **Mismatch (Swiss)** | Swiss Pairs and Swiss Teams | The match was drawn against the wrong opponents. Choose which side was mismatched and how — see [Reviewing Swiss mismatches](#reviewing-swiss-mismatches). |

   The rulings that affect a whole match (Void Match, Mismatch) apply to every
   board of that match, whichever board you opened.
5. The correction is saved, and anyone viewing that board sees the updated
   result.

### A board played the wrong way round

Sometimes a board is played with the pairs in the opposite directions to the
movement, most often because the arrows weren't switched. The result is
recorded against the wrong pairs: the pair the movement put North-South really
played East-West, and the other way round.

You don't need to change the result. Mark that one board instead:

1. From the Manage Game Menu, tap **Travellers** and choose the board.
2. Tap the row for the table where it happened.
3. Tap **Mark Played Reversed**.

The result stays exactly as entered, but the board is now credited the other
way round. The traveller and the board result screens show the NS and EW pair
numbers swapped, and the score goes to the pair that actually sat in that
direction. The leaderboard, the results and the exported USEBIO file all follow.
The board is still compared with every other table's result in the same way, so
only that table's two pairs (or, in a teams match, the two teams) change.

- It applies to **one table's copy of one board**. If the pairs were reversed
  for several boards, mark each of them.
- It works in every kind of event, and you can do it at any time, even before a
  result has been entered.
- It's separate from the other rulings. You can mark a board reversed and also
  correct its score or cancel it.
- To undo it, tap the same row and choose **Clear Reversed**. The original
  pairs and scores come straight back.

It doesn't change a **Board Not Played** or **Void Match** ruling.

## Entering the deals

You can record the dealt cards (the four hands) for any board — useful when you
want the hands on the traveller and in the exported results. Players can also
enter them from their own devices after a round, but as director you can enter
or correct any board at any time.

1. From the Manage Game Menu, tap **Enter Deals**.
2. Choose the **board number**.
3. Lay out the four hands: pick a direction (North, East, South, West) and tap
   that hand's cards. A card already placed in another hand can't be reused, and
   each hand holds 13 cards. If the board already has cards entered, they are
   shown ready for you to adjust.
4. Tap **Save deal** once the full deal of 52 cards is in. It is saved
   straight away, replacing any earlier entry, and appears for anyone viewing
   that board's hand.

Every board's cards are the same across sections, so a board only needs its
deal entered once.

### Importing the deals from a PBN file

If your boards were dealt by a dealing machine (such as a Duplimate), the
machine can give you a **PBN** file (ending in `.pbn`) holding every board's
hands. Import it instead of entering the hands one board at a time, whether by
you or by the players.

**Get the file onto your phone or tablet first.** The Bridge Box only needs the
file on the device you are directing from. Email it to yourself, send it with
AirDrop, or save it to a cloud drive, then open it from that device. You don't
need an internet connection for the import itself: it works over the Bridge Box
network.

1. From the Manage Game Menu, tap **Enter Deals**, then **Import from PBN
   file** at the bottom of the screen.
2. Tap the file chooser under **PBN file** (its button reads "Choose file" or
   "Browse", depending on your device) and pick the `.pbn` file. If your
   device won't let you pick it, open the file, copy its text and paste it into
   **Or paste PBN text** instead.
3. Check the preview before importing. It tells you how many boards were found
   in the file and how many of the event's boards are missing, for example "32
   boards found, 0 missing". It may also list:
   - **Event boards not in the file** — boards your event plays that the file
     doesn't cover. These keep whatever hands they already have.
   - **Not in this event, so skipped** — boards in the file that your event
     doesn't play. They are ignored.
   - Boards in red that couldn't be read, with the reason (see below). The
     other boards can still be imported.
4. Tap **Import {n} boards**. When it finishes you see "{n} boards imported";
   tap **Done** to go back to the Manage Game Menu.

**Importing replaces existing hands.** For every board in the import, the hands
from the file take the place of any hands already entered, including ones
players typed in. Boards that aren't in the file are left alone. You can import
at any time, before or during play, and anyone looking at those boards sees the
hands appear straight away.

Only the hands are read from the file. The dealer and vulnerability still follow
the board number as usual, and anything else in the file (players, results,
bidding and play) is ignored.

If the file has no board numbers, the boards are numbered 1, 2, 3 and so on in
the order they appear in the file.

**If something goes wrong**

| What you see | What it means |
| --- | --- |
| "That file is too large to be a PBN deal file." | The file isn't a normal deal file. Check you picked the right one. |
| "Could not read that file. Try pasting its text instead." | Your device couldn't open the file. Copy its text and paste it instead. |
| "Deal is incomplete (one or more hands are not given)" | The file has a board with a missing hand. Fix the hand with **Enter Deals** after importing the others. |
| "Board {n} appears more than once; the first one was used" | The file lists the same board twice. Only the first is imported. |
| "Game has no Board number" or "Invalid board number" | Some boards have no usable number while others do. Fix the file, or enter that board by hand. |
| "Game has no Deal" | A board in the file has no hands. |
| "Board {n} is not a complete deal" after tapping Import | The Bridge Box rejected the deal, and **nothing** was imported. Fix the file and try again. |
| "Failed to import the deals", "Failed to save deals", or "Timeout waiting for deal:importBulk" | The import didn't complete, usually because the connection dropped. Nothing was imported, and the file or text you chose is still there; tap Import again. |

## Sharing director access

If a co-director needs to help manage the game from their own phone or tablet,
share access with a short code:

1. Tap the menu (hamburger) icon in the header of any director screen and
   choose **Share Director Access**. Use the back arrow afterwards to return
   to the page you were on.
2. A short share code appears on screen.
3. The other person opens **Manage Game**, taps the same game, and enters the
   code on the **Claim Director Code** screen.
4. They now have full director access to that game from their device.

Director access is stored per device and per game, so several games can be
directed from the same device at once, and a co-director keeps access on their
own device.

## Exporting and publishing results

At the end of the session, open the Manage Game Menu and tap **Export &
Publish**.

### Checking you're ready

The first screen is a checklist of what the exports need, each marked
**Ready**, **Warning**, **Not ready** or **Optional**, with a summary at the
top:

- **Results entered** — whether every board has a result. While some are still
  outstanding it shows how many. When only a few are left, tap it to see which
  boards they are (round, table and board, with the pairs who should play it),
  so you know who to chase.
- **Club information** — the club name and EBU number. Without them no results
  file can be made; set them in **Settings → EBU**.
- **BridgeWebs** and **EBU** — whether this Bridge Box is set up to publish to
  each (in **Settings → BridgeWebs** and **Settings → EBU**). These are
  optional: if one isn't set up, only that upload is unavailable.

The checklist never stops you. Tap **Continue to Export Options**.

### The export options

- **Download USEBIO** — the results as a standard **USEBIO XML** file, to send
  to the EBU or import into a scoring program. Available once every result is
  in.
- **Download PBN** — the deals entered for the boards (see
  [Entering the deals](#entering-the-deals)), as a PBN file. Available at any
  time, since it doesn't depend on the results.
- **Upload to BridgeWebs** — publish the results to the club's BridgeWebs
  website. Shown only when BridgeWebs is set up, and available once every
  result is in.
- **Submit to EBU** — submit the results to the EBU. Shown only when the EBU is
  set up, and available once every result is in. The app checks the file and
  the players with the EBU first, and shows any notes (such as another event
  already submitted for that date, or a surname that doesn't match the EBU's
  records) before you submit.

The USEBIO file (which is also what goes to BridgeWebs and the EBU) matches the
kind of event you ran: an ordinary pairs game exports as a pairs event, while **Swiss Pairs** and **Swiss Teams** export in their own
format — round by round, with each match and its Victory Points — so a Swiss
event imports correctly rather than looking like a plain pairs game.

If the cards for a board have been entered (see **Entering the deals**), those
hands are included in the exported file alongside that board's results.

## Tips for directors

- **Set up before players arrive** — create the game and open the Tables tab so
  players can sit down straight away.
- **Odd number of pairs?** A sit-out is handled for you — the app shows which
  seat sits out each round, so you can start with a half table.
- **Someone running late?** Mark their empty seat **Expected late** on the
  Tables tab and start on time; seat them when they arrive. You can do this for
  as many missing pairs as you need.
- **Use sections** for large events — each section gets its own tables and
  movement, and the leaderboard shows both per-section and combined standings.
- **Share access** so a co-director can help — they manage from their own phone
  after claiming your share code.
- **Export at the end** — remember to download or publish the results (**Export
  & Publish**) before deleting the game.

For the shared-screen timer and leaderboard, see the
[Room Display Guide](room-display-guide.md). For the Bridge Box's WiFi, club
details, and admin key, see the [Settings Guide](settings-guide.md).
