MP → VP CONVERSION TABLES (for verification before coding)
===========================================================

These transcribe the two screenshots supplied. Each cell is the "% of
available match points NOT EXCEEDING" threshold — i.e. the UPPER bound of the
band that awards the VP split on that row. The winner's % is looked up against
the column for the match's board count; the loser gets (pool − winnerVP).

Reading rule (example, 20-VP table, "7-9 boards" column):
  - winner % <= 50.65            -> 10-10
  - 50.65 < winner % <= 51.98    -> 11-9
  - ...
  - winner % <= 68.35            -> 19-1
  - winner % >  68.35            -> 20-0
(So each printed number is the top of that row's band; the next row starts just
above it. The final 20-0 / 10-0 row is "more than" the previous threshold.)

DECISIONS (confirmed)
===========================================================
1. Table split — CONFIRMED. A half-match round uses Table A looked up by the
   HALF's board count; a full/ordinary round uses Table B by the full board
   count.

2. Out-of-range board counts — the UI must CAP boards/round so neither table is
   exceeded (full match never above the 20-27 column; a half, = floor(bpr/2),
   never above 10-13). The 28-39 and 40-55 full-match columns are dropped so the
   two tables stay over a consistent board range. Defensively, the lookup clamps
   to the last in-range column.

3. "Not exceeding" boundaries — CONFIRMED. A % EQUAL to a printed threshold
   stays in that (lower) band: the band is `pct <= threshold`, the next band
   strictly greater.

4. Winner-side lookup + mirror — CONFIRMED. Look up from the side with pct >= 50
   (exactly 50% is the dead-even split: 5-5 / 10-10). A pair below 50% gets
   `pool - lookup(100 - pct)`. Worked example: 40% on a full match = 20 - (VP
   for 60%). Scoring stays INDEPENDENT per pair (a pair's % is vs the whole
   field, not strictly complementary to one table opponent), so two pairs' VPs
   need not sum to the pool.
